# Security policy

## Security principles

- default to least privilege
- reject unsafe external values and untrusted input
- keep secrets outside source control
- enforce server-side authorization for every protected action
- document any installation or deployment gap before production use

## Reporting vulnerabilities

If a security issue is discovered, report it privately to the maintainer with the relevant reproduction details, impact, and evidence. Avoid public disclosure until a fix is implemented and users have been informed if required.

## Security posture

This repository is not yet a production healthcare backend. It should be treated as a prototype until backend authentication, authorization, storage, and deployment controls are completed and independently reviewed.
